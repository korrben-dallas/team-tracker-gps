# Team Tracker GPS — групповой трекер GPS

Приложение для совместных выходов на природу: треки всех участников группы видны на одной карте. Каждый трек — широкая полупрозрачная полоса реальной ширины в метрах. Цвет полосы показывает давность: **красный** — только что, **жёлтый** — недавно, **зелёный** — давно. Цвет меняется по каждой точке, поэтому трек выглядит как линия времени, привязанная к карте.

Есть две версии с общей базой: **приложение для iPhone из App Store** (трек пишется и при выключенном экране) и **веб‑версия** (PWA) для Safari и Android. Обе работают без интернета.

## Группы и профили

Участники видят треки и метки **только своей группы**. Сменить группу можно круглой кнопкой справа вверху, под кнопкой слоёв карты: откроется раскрывающийся список.

**Три встроенных профиля** — общие группы с фиксированными настройками:

| Профиль | Полоса | Красный → зелёный | Треки видны | После позеленения | Погрешность GPS | Не писать быстрее |
|---|---|---|---|---|---|---|
| 🍄 Грибники | 7 м | 3 дня | 3 дня, на 4‑й день исчезают | — | 30 м | 7 км/ч |
| 🧭 Волонтёры‑поисковики | 30 м | 1 день | 14 дней | прозрачность 70 % | 20 м | 7 км/ч |
| 🥾 Пешие туристы | 5 м | 30 дней | 90 дней | — | 20 м | 9 км/ч |

**Свои группы.** Любой участник может создать группу: название, аватарка, описание, тип (набор меток) и все настройки треков ползунками:
- ширина полосы;
- время от красного до зелёного;
- сколько дней показывать треки;
- допустимая погрешность GPS;
- порог скорости;
- прозрачность позеленевших треков.

Настройки действуют у всех участников, менять их может **только создатель**. В группу вступают по коду или ссылке‑приглашению.

## Возможности

- Регистрация: только ник и фото (по желанию), без телефона и почты. При входе нужно принять правила сообщества и выбрать профиль или группу.
- **Запись трека**: кнопка «Начать запись трека». Точки сохраняются в телефон сразу, на сервер уходят при появлении связи.
- **Фильтры записи** (по настройкам группы):
  - точки с погрешностью GPS больше порога не пишутся;
  - при скорости выше порога группы трек не пишется: поездка на машине не попадает на карту;
  - на экране записи видно почему: «GPS ± 35 м — не пишу» или «🚗 24 км/ч — не пишу».
- Непрозрачность полосы всегда 50 %. У поисковиков позеленевшие треки становятся прозрачнее (70 %).
- Нажатие на полосу показывает, кто и когда здесь проходил. Аватары участников видны на карте в месте их последней точки.
- **Метки** (жёлтая кнопка с булавкой). Набор видов зависит от типа группы:
  - грибники: грибы, грибное место, ягоды;
  - поисковики: след, вещь, найден человек, осмотрено, штаб;
  - туристы: вид, родник, стоянка, тропа;
  - во всех группах есть «Опасно», «Машина» и «Другое».

  К метке можно добавить фото и описание. Кнопка **«Для меня»** — личная метка, хранится только в телефоне; кнопка **«Для всех»** — метку видит группа, и она даёт +1 балл.
- **Рейтинг** (🏆) у каждой группы свой: отдельно у грибников, у поисковиков, у туристов и в каждой созданной группе. Считается так: 1 балл за каждый километр, пройденный в этой группе не быстрее её порога скорости, плюс 1 балл за каждую общую метку в этой группе.
- **GPX**: последний трек с вашими метками или все ваши треки. Свои треки хранятся в телефоне год, даже если с карты они уже пропали, например у грибников через 3 дня.
- Две подложки: **OSM Topo** (OpenTopoMap) и **спутник** (Esri). Карту района можно скачать заранее и пользоваться без интернета.
- Обмен треками и метками файлом через AirDrop, если нет связи.
- Модерация:
  - жалоба ⚑ на метку, ник или фото;
  - скрытие участника;
  - фильтр мата;
  - удаление аккаунта в приложении.

## Шаг 1. Сервер (Supabase, бесплатно)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте **New project**. Регион лучше выбрать поближе, например Frankfurt.
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**. Скрипт безопасно запускать повторно: после каждого обновления приложения запускайте его снова.
3. Найдите адрес и ключ:
   - **адрес**: адресная строка браузера выглядит как `supabase.com/dashboard/project/ИДЕНТИФИКАТОР`, значит адрес проекта — `https://ИДЕНТИФИКАТОР.supabase.co`. Его же показывает кнопка **Connect** вверху страницы проекта;
   - **ключ**: Project Settings → API Keys → **Publishable key** (`sb_publishable_…`) или anon public. Секретный ключ не используйте.
4. Заполните `docs/js/config.js`:

```js
export const DEFAULT_CONFIG = {
  supabaseUrl: 'https://ИДЕНТИФИКАТОР.supabase.co',
  supabaseKey: 'sb_publishable_…',
  webUrl: 'https://ВАШ_ЛОГИН.github.io/team-tracker-gps/',
  appStoreUrl: '',            // впишете после публикации
  supportEmail: 'ваша@почта'  // Apple требует контакт для жалоб
};
```

> Бесплатный проект Supabase «засыпает» после недели без запросов. Разбудить его можно кнопкой в панели Supabase.

## Шаг 2. Репозиторий на GitHub и веб‑версия

1. Создайте на GitHub репозиторий `team-tracker-gps`, публичный или приватный.
2. Загрузите в него **содержимое** архива: папки `docs`, `ios`, `supabase`, `store`, `.github` и файлы `package.json`, `package-lock.json`, `capacitor.config.json`, `.gitignore`, `README.md`.
   Проще всего через [GitHub Desktop](https://desktop.github.com) или командой:
   ```bash
   git init && git add . && git commit -m "Team Tracker GPS"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/team-tracker-gps.git
   git push -u origin main
   ```
   Через веб‑форму «Upload files» папка `.github` может не загрузиться: имена, начинающиеся с точки, скрыты. Тогда создайте файл `.github/workflows/ios-testflight.yml` вручную через **Add file → Create new file** и вставьте в него содержимое.
3. Откройте **Settings → Pages → Deploy from a branch**, ветку **main**, папку **/docs** и нажмите **Save**.
   Через пару минут веб‑версия откроется по адресу `https://ВАШ_ЛОГИН.github.io/team-tracker-gps/`. Там же будут адреса для App Store:
   - `…/privacy.html` — политика конфиденциальности;
   - `…/terms.html` — правила.
   Если репозиторий приватный, Pages работает только на платном тарифе GitHub. Тогда сделайте репозиторий публичным: ключ Supabase в `config.js` публичный по назначению.

## Шаг 3. App Store

### Что нужно
- **Apple Developer Program** — $99 в год, [developer.apple.com/programs](https://developer.apple.com/programs/). Регистрация идёт через Apple ID с включённой двухфакторной защитой и занимает от 1 до 3 дней.
- **Mac не нужен.** Приложение собирается на Mac в облаке GitHub Actions. Для публичных репозиториев это бесплатно, для приватных бесплатных минут хватает на несколько сборок в месяц.

### 3.1. Идентификатор приложения
1. Выберите уникальный идентификатор, например `ru.ВАШЕИМЯ.teamtracker`, и замените `ru.teamtracker.gps` на него:
   - в `capacitor.config.json` (`appId`);
   - в `ios/App/App.xcodeproj/project.pbxproj` (2 строки `PRODUCT_BUNDLE_IDENTIFIER`).
2. Зарегистрируйте его: [developer.apple.com/account](https://developer.apple.com/account) → **Certificates, IDs & Profiles → Identifiers → +** → App IDs → App. Explicit Bundle ID — ваш идентификатор. Дополнительные возможности (Capabilities) не нужны.

### 3.2. Карточка приложения
[appstoreconnect.apple.com](https://appstoreconnect.apple.com) → **Apps → + → New App**:
- платформа — iOS;
- название — «Team Tracker GPS» (если занято, например «Team Tracker GPS — групповой»);
- основной язык — русский;
- Bundle ID — ваш из шага 3.1;
- SKU — любой, например `team-tracker-gps`.

### 3.3. Ключ API для облачной сборки
App Store Connect → **Users and Access → Integrations → App Store Connect API → Team Keys → +**:
- имя — `GitHub`, роль — **Admin** (без неё облачная сборка не сможет сама создать сертификат подписи);
- скачайте файл `AuthKey_XXXXXXXXXX.p8`. Скачать его можно только один раз;
- запишите **Key ID** и **Issuer ID** со страницы ключей;
- **Team ID** — на [developer.apple.com/account](https://developer.apple.com/account) → Membership details.

### 3.4. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `APPLE_TEAM_ID` | Team ID (10 символов) |
| `ASC_KEY_ID` | Key ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8_BASE64` | файл .p8 в base64 (см. ниже) |

Как получить base64:
- Mac: `base64 -i AuthKey_XXXX.p8 | pbcopy`, затем вставить;
- Windows (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("AuthKey_XXXX.p8")) | Set-Clipboard`.

### 3.5. Сборка и TestFlight
1. GitHub → вкладка **Actions** → **iOS → TestFlight** → **Run workflow**. Сборка идёт 10–20 минут.
2. Через 10–30 минут сборка появится в App Store Connect → ваше приложение → **TestFlight**.
3. Установите приложение **TestFlight** на iPhone, добавьте себя во внутренние тестировщики и проверьте:
   - запись трека с выключенным экраном;
   - метки;
   - GPX;
   - удаление аккаунта.

Номер версии берётся из `package.json` (`version`), номер сборки растёт сам с каждым запуском.

### 3.6. Страница в App Store и отправка на проверку
Все тексты для копирования лежат в **`store/app-store-ru.md`**:
- подзаголовок, описание, ключевые слова;
- ответы на анкету **App Privacy**;
- возрастной рейтинг;
- заметки для проверяющего **(App Review Notes)**.

Кроме текстов понадобятся:
- **скриншоты iPhone 6,9″** (1320 × 2868 или 1290 × 2796), от 3 до 10 штук. Их проще всего снять на iPhone Pro Max из TestFlight‑версии: карта с треками, метка с фото, рейтинг, запись похода;
- **Privacy Policy URL**: `https://ВАШ_ЛОГИН.github.io/team-tracker-gps/privacy.html`;
- **Support URL**: адрес веб‑версии или страница с почтой.

Затем: версия 1.0 → **Build** → выбрать сборку → **Add for Review** → **Submit**. Проверка обычно занимает 1–3 дня.

## Модерация (раз в день)
Apple требует реагировать на жалобы в течение 24 часов. В Supabase откройте **SQL Editor** и выполните:
```sql
select * from reports where not resolved order by t desc;
```
Готовые команды, чтобы скрыть метку, сменить ник, удалить контент нарушителя и закрыть жалобу, — в конце `supabase/schema.sql`. Можно также открыть **Table Editor → reports**.

## Обновления
- Изменили что‑то в `docs/`:
  - для веб‑версии увеличьте `VERSION` в `docs/sw.js`, и у всех она обновится при следующем запуске;
  - для App Store увеличьте `version` в `package.json`, запустите сборку (шаг 3.5) и отправьте новую версию на проверку.
- Изменили `supabase/schema.sql`: выполните его заново в SQL Editor.

## Ограничения
- **Веб‑версия (Safari):** экран должен быть включён во время записи. В приложении из App Store такого ограничения нет: в строке состояния горит синий значок геолокации, запись идёт в фоне.
- Без интернета треки других не обновляются. Ваш трек уйдёт на сервер, когда появится связь. В лесу треками можно обменяться файлом через AirDrop.
- Скачивание района ограничено 4000 фрагментами за раз, это примерно лес 10 × 10 км. Серверы OpenTopoMap бесплатные и держатся на пожертвованиях, поэтому не скачивайте лишнего.
- Треки и общие метки видны участникам группы. Встроенные профили открыты для всех. В свою группу можно вступить только по коду: это 10 случайных символов, угадать его практически невозможно. Личные метки на сервер не попадают.
- Регистрации нет. Каждый телефон хранит секретный ключ аккаунта, а сервер принимает изменения только с ним. Поэтому чужие треки, метки и настройки группы изменить нельзя. Если телефон потерян или приложение удалено, ключ пропадает вместе с ним. Созданной группой тогда управлять будет нельзя, но она продолжит работать.

Проверить веб‑версию локально: `cd docs && python3 -m http.server 8000` → http://localhost:8000.
